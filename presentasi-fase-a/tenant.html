03 / Keamanan Data

Tenant isolation menjadi fondasi keamanan data institusi

Mekanisme Fail-Closed

Query database secara otomatis dibatasi pada level model. Jika konteks tenant tidak ditemukan, sistem menolak memberikan data untuk mencegah kebocoran antar-institusi.

Isolasi dilakukan pada lapisan aplikasi dan database menggunakan Global Scopes, memastikan setiap institusi hanya dapat mengakses data miliknya sendiri secara transparan.

Komponen Inti

TenantContext (Singleton)

Pusat kendali identitas institusi yang aktif dalam satu siklus request.

Middleware Resolver

Mendeteksi institusi dari Header, Session, atau Route secara otomatis.

Membership Validation

Memastikan pengguna memiliki hak akses aktif pada institusi terkait.

Implementasi: Laravel Middleware + Eloquent Global Scopes
