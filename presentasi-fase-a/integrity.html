04 / Database Integrity

Fase A memperkuat integritas database dan lifecycle tenant

Skema & Relasi

• Penambahan Foreign Key pada 40+ tabel domain akademik.
• Unique Constraint untuk NIM, NIDN, dan Kode Mata Kuliah per Tenant.
• Indexing strategis untuk performa query dan deteksi konflik jadwal.
• Normalisasi ID dan tipe data yang sepenuhnya MySQL-ready.

Lifecycle Tenant

• Status: Trial, Active, Suspended, Inactive.
• Transition Service memvalidasi alur perubahan status institusi.
• Audit Trail mencatat setiap perpindahan dan alasan perubahan.
• Tenant Switcher Action dengan validasi membership aktif.
